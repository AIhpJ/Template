# Template

This repo now includes two simple starter pieces:

- `quicksort.py`: a small Python quicksort example with a self-test
- `index.html` + `script.mjs` + `snake-core.mjs`: a browser-playable Snake v1

Quick checks:

```bash
python3 quicksort.py
node snake.test.mjs
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser to play the game.
